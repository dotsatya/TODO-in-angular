# ✅ TodoList App

A clean and modern Angular to-do application for managing daily tasks with a simple and responsive interface.

This project lets users add new tasks, update existing ones, and delete completed items through an elegant task manager layout.

## ✨ Features

- Add a new task instantly
- Update an existing task from a modal popup
- Delete tasks with one click
- Simple and clean responsive layout
- Built with Angular 22 and modern frontend patterns

## 🚀 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run the app locally

```bash
npm start
```

Then open:

```bash
http://localhost:4200/
```

The app will automatically reload when you make changes to the source files.

## 🧩 App Behavior

This project is a basic task manager where users can:

- type a task into the input field,
- click Add to insert it into the list,
- click Update to edit the task in a popup,
- click Delete to remove it from the list.
